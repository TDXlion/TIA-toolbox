# 博途工具箱

帮工科学生解决博途（TIA Portal）安装与使用问题。从环境自检到卸载重装，覆盖全流程。

## 它解决什么问题

装博途时你可能会遇到：

- 安装前不知道自己电脑能不能装，下了 30GB 才发现不行
- 装到一半反复要求重启，无限循环
- 装崩了系统变卡，只能刷机
- 装好了打不开，提示"找不到许可证"
- 编译报错、PLC 连不上，不知道从哪查

这个工具把这些问题变成几个选项，双击运行，按提示操作。

## 功能

| 模块 | 说明 |
|---|---|
| 环境自检 | 检查系统、内存、磁盘、.NET、MSMQ 等，红黄绿报告 |
| 自动修复 | 缺 .NET 3.5 和 MSMQ 时，自动启用 |
| 推荐方案 | 根据用途和硬件，推荐装哪些组件 |
| 安装包检测 | 数字签名验证 + 病毒扫描 + 破解工具识别 |
| 安装监控 | 实时翻译安装日志，卡住时判断是正常还是异常 |
| 安全退出 | 装崩了不刷机：残留检测、挂起重启修复、注册表清理 |
| 授权引导 | 检测 ALM 服务，一键打开许可证管理器 |
| 日常使用 | 进程查看/清理、启动项检查、错误码查询 |
| 卸载重装 | 备份许可证、官方卸载工具引导、重装前检查 |
| 问题反馈 | 任何界面按 F 键，自动打包现场信息 |

## 快速开始

### 1. 下载

从 [Releases](https://github.com/TDXlion/TIA-toolbox/releases) 下载最新版压缩包，解压到任意位置。

### 2. 运行

双击 `博途工具箱.bat`。

会弹出 UAC 提权窗口，点"是"。

### 3. 选择

进入主菜单后，选择你当前的状态：
[1] 还没下载安装包
[2] 下载了，还没装
[3] 装过了，出问题了
[4] 装好了，想优化
[5] 我要开始安装了，帮我盯着
[6] 我要找人帮忙，打包诊断日志
[7] 博途打不开，提示找不到许可证
[8] 日常使用（进程/启动项/错误码）
[9] 卸载/重装
[0] 退出

### 4. 遇到问题

**任何界面按 F 键**，工具会自动收集现场信息，在桌面生成一个压缩包。

你可以选择发给我，也可以自己留着。

## 常见问题

**Q：为什么需要管理员权限？**

A：因为要修改系统注册表、启用 Windows 功能、读取服务状态。这是操作系统的要求。

**Q：会不会误删我的东西？**

A：所有破坏性操作都会：
1. 先创建系统还原点
2. 备份注册表
3. 要求你确认
4. 记录到日志

**Q：杀毒软件报毒怎么办？**

A：工具本身是纯 PowerShell 脚本，没有可执行文件。如果报毒，把完整路径发我，我看看是不是误报。

**Q：能装在 Linux 上吗？**

A：暂时只支持 Windows。Linux 版本在计划中，但优先级较低（博途本身只支持 Windows）。
